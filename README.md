## 📂 Highlighted Projects

### 1. **PowerMRO ⚙️ — Telemetry & Equipment Health Dashboard**
> *Full-stack control room dashboard that monitors industrial telemetry and predicts equipment faults.*
- **Tech Stack:** `Next.js`, `TypeScript`, `Tailwind CSS`, `Recharts`, `React Hooks`, `CI/CD (GitHub Actions / Vercel)`
- **Telemetry Engine:** Simulated live sensor streams (Temperature, Pressure, Vibration) and automated threshold-crossing alerts.
- **RUL Engine:** Calculated Remaining Useful Life (RUL) of machine units utilizing historical failure intervals for predictive maintenance.
- **Visual Analytics:** Interactive dashboards displaying fleet downtime, repairs cost, and fault distribution charts.

### 2. **GameIQ 🎮 — Player Behavior Analytics & Churn Prediction**
> *End-to-end Machine Learning pipeline and API validating player retention telemetry.*
- **Tech Stack:** `Python`, `Flask`, `Scikit-Learn`, `Pandas`, `Random Forest Classifier`, `REST APIs`
- **Predictive Accuracy:** Deployed model predicting user churn for **90,000+ mobile game users** at **86.8% accuracy**.
- **Automated Pipeline:** Formulated data ingestion, cleaning, feature engineering, and inference REST API scripts in Python.
- **Retention Insight:** Analyzed key retention drivers, identifying A/B testing thresholds like game gate placements.

### 3. **Interactive Weather & Environmental Dashboard 🌦️**
> *Highly responsive API-driven frontend dashboard demonstrating clean asynchronous execution.*
- **Tech Stack:** `JavaScript (ES6+)`, `REST APIs (OpenWeather)`, `HTML5/CSS3`, `DOM Manipulation`
- **Robust Client Integration:** Designed with strict promise handling, custom local preferences caching, and custom fallback error flows for edge cases.
